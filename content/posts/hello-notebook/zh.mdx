這個部落格的每一篇文章都是一個資料夾，裡面放 `zh.mdx`，需要英文版時再加 `en.mdx`。互動元件放在同一個資料夾的 `components/`，由文章自己 `import`，所以每篇文章的程式碼只會在那一篇載入。

## 內文

內文使用襯線字體，欄寬控制在 68 個字元左右，行高放得比較鬆，長文讀起來比較不累。**粗體**用在第一次出現的名詞，*斜體*用在強調，`行內程式碼`用在識別字。連結長[這樣](https://nextjs.org)。

邊注用來放「值得一提、但會打斷思路」的內容。<Sidenote>像這樣。在寬螢幕上它會出現在右側的留白裡，和引用它的那一行對齊；在手機上，點一下編號就會在行內展開。</Sidenote> 寫作時盡量讓正文不看邊注也讀得通。

> 引用長這樣。適合放一句別人說過、而且說得比你好的話。

## 程式碼

程式碼區塊用 Shiki 上色，深淺色主題各有一組配色。可以加檔名，也可以標出重點行：

```ts title="lib/ml/ops.ts" {3}
export function relu(x: Tensor): Tensor {
  const out = zeros(x.shape);
  for (let i = 0; i < x.data.length; i++) out.data[i] = Math.max(0, x.data[i]);
  return out;
}
```

## 數學式

行內數學式像 $\mathrm{softmax}(z)_i$，獨立成行的則置中：

$$
\mathrm{softmax}(z)_i = \frac{e^{z_i - \max(z)}}{\sum_j e^{z_j - \max(z)}}
$$

減去 $\max(z)$ 不會改變結果，但可以避免 $e^{1000}$ 溢位。

## 表格

| 元件 | 用途 | 寬度 |
| --- | --- | --- |
| `Figure` | 靜態圖片或圖表 | inline / wide / full |
| `Instrument` | 互動元件的外框 | inline / wide / full |
| `Sidenote` | 邊注 | 右側留白 |
| `Callout` | 提示框 | 內文寬度 |
